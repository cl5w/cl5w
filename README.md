## Hey, I'm Claw.

### About me

I'm **cl5w**, a software developer from Türkiye and the founder of **[DyPlugin / Dynasty Plugins](https://github.com/DyPlugin)**. You may also see me as **Claww** on plugin releases.

I work with **Java, TypeScript and JavaScript**, building Minecraft server plugins, Discord tools and web projects. My focus is practical software with clear configuration and features that solve a specific problem.

At Dynasty Plugins, that means helping server owners protect their worlds, give players useful teleportation tools and connect their Minecraft and Discord communities.

## Selected projects

| Project | What it does |
| --- | --- |
| **[DyClaim](https://github.com/DyPlugin/DyClaim)** | Chunk-based land protection with trust, ownership management and optional economy features. |
| **[DyRTP](https://github.com/DyPlugin/DyRTP)** | Random teleportation with destination safety checks, world profiles and biome selection. |
| **[DyDiscord](https://github.com/DyPlugin/DyDiscord)** | Connects Minecraft and Discord through account linking, chat, roles and server updates. |
| **[DyHomes](https://github.com/DyPlugin/DyHomes)** | Homes, warps and spawn with rank limits, DyClaim trust integration and Folia support. |
| **[Role Copy Bot](https://github.com/cl5w/discordRoleCopyBot)** | A JavaScript Discord bot for copying a selected range of roles between servers. |

Explore the Minecraft collection at **[dynastyplugins.com](https://dynastyplugins.com)** or browse the source at **[github.com/DyPlugin](https://github.com/DyPlugin)**. Platform support, downloads and license terms are documented in each project's repository.
